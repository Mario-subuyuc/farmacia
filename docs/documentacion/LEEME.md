# Documentación del proyecto NexoFarma

El archivo principal es **NexoFarma_Documentacion_Integral_RUP.docx**. Integra las entregas solicitadas y la referencia técnica del proyecto. El índice y las páginas se actualizaron mediante Microsoft Word durante la revisión.

También se entregan por separado:

- 01_Vision_del_negocio.docx
- 02_Vision_del_sistema.docx
- 03_Arquitectura_del_negocio.docx

## Contenido de la versión integral

Análisis RUP; visión de negocio y del sistema; arquitectura del negocio y procesos; 42 requisitos funcionales, 16 no funcionales y 22 reglas de negocio; 18 casos de uso; matriz de trazabilidad; factibilidad técnica, económica y operativa; diagramas E-R general y por dominios; arquitectura técnica y nube; desarrollo, API, seguridad, despliegue, pruebas, riesgos y transición. Anexos: guía por perfil, glosario, diccionario de 38 tablas/339 columnas y lista de 69 relaciones FK.

La institución, curso, autor académico y firmas quedan por completar porque no fueron proporcionados. Los presupuestos y beneficios son escenarios ilustrativos y no cotizaciones ni resultados reales. Se diferencia implementación, propuesta y validación pendiente.

## Uso

Abrir el DOCX en Microsoft Word. Si se edita, actualizar el índice con F9 / Actualizar tabla. Las láminas E-R están en páginas apaisadas. Para ampliar o editar un diagrama, consultar figuras/: PNG, SVG y fuente Graphviz DOT. El Markdown contiene el texto versionable. modelo-datos.json contiene metadatos; no incluye filas de clientes ni credenciales.

La documentación tiene fecha de corte 18/10/2026. El prototipo sigue siendo referencia funcional y no se declara una operación nacional certificada. Las fuentes y referencias están dentro del expediente.
